在下面改公司 / 岗位 / JD / 简历，缺口即时重算，勾题就能出稿。 数据和 API Key 都在你这台机器上：画像存浏览器本地，Key 是密文，只在内存里解一次。

三点实话：① 这个版本没有服务器，画像和稿件都存在你这台机器的浏览器里，换设备/清缓存会丢——重要的先「下载全部稿件」导出； ② 请求由浏览器直连模型（Key 是密文，只在内存里解一次，不经过任何第三方），公司网络或拦截插件挡住时才会退到公共代理，那时会慢； ③ 没有跨设备缓存，同一道题改一次简历就重算一次，比在线版多花点额度。 想省事用在线版：https://a1bb3b6066bf43ba2.app.workbuddy.host/portal
