导出 XMind

把题目贴进来

群面材料、单面题、JD 都行。选一个框架类型，生成后可以再改。

推荐下载 .xmind：这是 XMind 自己的文件类型，装过 XMind 的电脑双击就直接打开，不用再导入。
.mm / .opml 是通用交换格式，系统一般没关联，双击只会用浏览器打开源码 —— 需要在 XMind 里「文件 → 导入 → FreeMind / OPML」。老版本 XMind（8 及以前）打不开 .xmind 时，用这两个兜底。
连文件都不想存：点右上「复制大纲」，在 XMind 画布里直接粘贴，会自动分层。
